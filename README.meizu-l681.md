# Meizu M3 Note (L681) kernel

Android kernel sources for the Meizu M3 Note L681 / MediaTek MT6755.
The `cm-14.1` branch targets LineageOS 14.1 and recovery builds.

See [ReMeizu](https://github.com/nomorecoolnicknames/remeizu) for project status.
Build outputs and device captures are kept outside this repository.

Based on the work of the Linux, Android, MediaTek, Meizu, LineageOS and recovery
communities. Original source notices and licenses are retained.
